通信工程科班出身（东南大学），做过 CV 算法，在马来西亚和法国常驻卖过货。现在是星尘智能的海外大科研销售经理，卖绳驱轮式双臂人形机器人整机 —— 但客户买的其实不是机器人，是一台能跑自己算法的载体。

所以我每天干的活，一半是商务，一半是技术：把「我要做 XX 研究」翻译成可交付范围，判断现有 SDK 撑不撑得住、哪部分必须二次开发、哪些能力得算法团队补。这件事和卖 API 是同一件事 —— 先把能力边界说清楚，再谈钱。

工作之外，我把 AI 真的接进了自己的动作里：七个每天在用的自建工具，公司全员 Token 消耗排进前十。不是「关注 AI」，是靠它干活。

4 个月、8 台整机、307 万（已回款），15 家客户进样机、4 家签约。这些数字只说这一次 —— 它解释不了我在做什么。
